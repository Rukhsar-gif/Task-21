# Responsive Navbar with Hamburger Menu

A responsive navigation bar created as **Task 21** of my
**Web Development Internship at Veda Technology**.

## Project Overview

This project is a responsive navigation bar that displays
horizontal navigation links on desktop screens and transforms into
a hamburger menu on smaller screens.

The mobile menu slides in smoothly using CSS transitions.

## Objective

The objective of this task was to practice:

- Responsive web design
- CSS media queries
- JavaScript toggle interactions
- DOM manipulation
- CSS transitions
- Accessible navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Horizontal desktop navbar
- Hamburger menu on mobile
- Slide-in mobile navigation
- Smooth open and close transition
- Active hamburger animation
- Navigation links
- Escape-key support
- Responsive design
- Accessible menu attributes
